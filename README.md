# Cek Titik Bangunan Tempeh

Aplikasi web untuk PPL, PML, dan admin SE2026 Kecamatan Tempeh: mencocokkan titik bangunan hasil olah peta (QGIS) dengan gambar peta WSS, menandai titik yang benar, dan membuat titik perbaikan bila lokasinya salah.

- Data (titik, batas SLS, scan, perbaikan) disimpan di Supabase dan dilindungi Row Level Security; repositori ini hanya berisi kode tampilan.
- Masuk dengan akun Google yang terdaftar di daftar alokasi petugas.
